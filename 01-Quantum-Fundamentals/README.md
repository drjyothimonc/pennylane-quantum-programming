
# 01 - Quantum Fundamentals

This folder introduces the fundamental concepts of
quantum computing using PennyLane and Python.

## Topics

1. Qubits and quantum states
2. Computational basis states
3. Quantum superposition
4. Probability amplitudes
5. Quantum measurements
6. Single-qubit state preparation
7. Bloch sphere representation

## Learning Objectives

After completing these experiments, learners will be
able to:

- Create quantum devices using PennyLane.
- Define quantum circuits using QNodes.
- Prepare and measure quantum states.
- Interpret quantum measurement probabilities.
- Visualize simple quantum circuits.

## Requirements

- Python
- PennyLane
- Jupyter Notebook
